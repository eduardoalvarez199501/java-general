# 🧠 Temas

### 🔢 Variables y tipos de datos

Ejemplos relacionados con:

* `int`
* `double`
* `float`
* `char`
* `boolean`
* `String`
* Declaración y asignación de variables
* Conversión de tipos

---

### ➕ Operadores aritméticos

Práctica de operaciones matemáticas utilizando:

```java
+
-
*
/
%
```

---

### ⚖️ Operadores de comparación

Ejemplos utilizando:

```java
==
!=
>
<
>=
<=
```

Estos operadores permiten comparar valores y obtener resultados booleanos.

---

### 🧩 Operadores lógicos

Práctica con:

```java
&&   // AND
||   // OR
!    // NOT
```

Ejemplo:

```java
int edad = 25;
boolean experiencia = true;

if (edad >= 18 && experiencia) {
    System.out.println("Cumple las condiciones");
}
```

---

### 🔀 Estructuras de control

Ejercicios para aprender a tomar decisiones dentro de un programa.

Incluye:

* `if`
* `else`
* `else if`
* `switch`

Ejemplo:

```java
if (edad >= 18) {
    System.out.println("Es mayor de edad");
} else {
    System.out.println("Es menor de edad");
}
```

---

### 🔁 Ciclos

Ejemplos de estructuras repetitivas:

* `for`
* `while`
* `do while`

Estas estructuras permiten ejecutar un bloque de código varias veces dependiendo de una condición.

---

### 📦 Arreglos

Ejercicios para trabajar con colecciones de datos utilizando arrays.

Ejemplo:

```java
String[] lenguajes = {
    "Java",
    "JavaScript",
    "Python"
};
```

---

### ⚙️ Métodos

Práctica de creación y utilización de métodos para organizar y reutilizar código.

Ejemplo:

```java
public static void saludar() {
    System.out.println("Hola, mundo!");
}
```
